## 倍增
```
倍增，顾名思义就是翻倍，它能够是先新的处理传化为对数级的处理，极大地优化时间复杂度
```
## 取模运算规律
```
当计算过程中只有加法和乘法，取模可以放在任意位置
（abcd）%p=((a%p)(b%p)(c%p)(d%p))%p
当计算过程中存在减法，计算结果可能存在负数的，此时如果需要补正，就需要模加模的技巧来补正
(a-b)%p=((a-b)%p+p)%p
当计算过程中，存在除法的时候，取模会造成结果错误 （求逆元）
```
## 快速幂示例
```
#include <iostream>

using namespace std;

typedef long long LL;

LL a, b, p;

// 快速幂的模板
LL qpow(LL a, LL b, LL p)
{
    LL ret = 1;
    while(b) {
        if(b & 1) ret = ret * a % p;
        a = a * a % p;
        b >>= 1;
    }
    return ret;
}

int main()
{
    cin >> a >> b >> p;

    printf("%lld^%lld mod %lld=%lld", a, b, p, qpow(a, b, p));

    return 0;
}
```
