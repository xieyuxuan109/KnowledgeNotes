## 当遇到多次询问区间和的时候使用前缀和
```
第一步 现预处理出来一个前缀和数组 f[i]表示区间【1，i】中，所有元素的和
       f[i]=f[i-1]+a[i]
第二步 利用前缀和数组
第三步 使用前缀和数组时 下标必须从1开始计数
```
## 差分 快速解决“将某一个区间所有元素统一加上一个数”操作
```
第一步 预处理一个差分数组 f[i]表示当前元素与前一个元素的差值 f[i]=a[i]-a[i-1]
第二步 利用差分数组解决m词修改操作 性质：原数组【L,R】区间全部加k这个操作相当于在差分数组中f[L]+=k f[R+1]-=k
同时也可以利用差分数组的定义来创建差分数组 f[i]+=a[i] f[i+1]-=a[i]
```
## 前缀和模板
```
#include <iostream>
using namespace std;
int n;
int arr[100001];
int m;
int prefix[100001];
int main(){
	cin>>n;
	for(int i=0;i<n;i++)cin>>arr[i];
	//构造前缀和数组
	for(int i=1;i<=n;i++)prefix[i]=prefix[i-1]+arr[i-1];
	cin>>m;
	for(int i=0;i<m;i++){
		int left;
		int right;
		cin>>left>>right;
		int temp=prefix[right]-prefix[left-1];
		cout<<temp<<endl;
	}
}
```
## 差分模板
```
#include <iostream>
#include <algorithm>
using namespace std;
typedef long long LL;

LL arrM[100010];
LL arrA[100010];
LL arrB[100010];
LL arrC[100010];
LL diff[100010];
LL number[100010];
LL price[100010]; 
int main(){
	LL M,N;
	cin>>N>>M;
	for(int i=0;i<M;i++)cin>>arrM[i];
	for(int i=1;i<M;i++){
		if(arrM[i]<arrM[i-1]){
			diff[arrM[i]]+=1;
			diff[arrM[i-1]]-=1;
		}else{
			diff[arrM[i]]-=1;
			diff[arrM[i-1]]+=1; 
		}
	}
	for(int i=1;i<=N;i++){
		number[i]=diff[i]+number[i-1];
	}
	LL money=0; 
	for(int i=1;i<N;i++){
		cin>>arrA[i]>>arrB[i]>>arrC[i];
		price[i]=min(arrA[i]*number[i],arrB[i]*number[i]+arrC[i]);
		money+=price[i];
	}
	cout<<money<<endl;	
}
```
