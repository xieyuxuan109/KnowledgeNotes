## 双指针算法是用来优化两个for循环情况的
```
性质：在暴力枚举过程中，left和right可以不回退
总共分五个步骤：
    初始化                              left=1 right=1 用什么结构来维护窗口信息？ unordered_map<int,int> map双关键字哈希表 元素，次数
    进窗口                              让right所指的元素进入窗口 map[a[right]]++
    判断窗口是否合法                     map[a[right]]>1
        出窗口(让left所指的元素出窗口)                              
    更新结果 ret=max(ret,right-left+1)
```
## 示例代码
```
#include <iostream>
#include <algorithm>
#define N 20010
using namespace std;
int n,m;
int arr1[N],arr2[N];

int main(){
    cin>>n>>m;
    for(int i=0;i<n;i++) cin>>arr1[i];
    for(int i=0;i<m;i++) cin>>arr2[i];
    sort(arr1, arr1+n);
    sort(arr2, arr2+m);

    int left1=0, left2=0, cost=0;

    while(left1 < n){
        // 骑士不够了
        if(left2 >= m){
            cout << "you died!" << endl;
            return 0;   // 直接结束，不再输出 cost
        }
        // 找第一个 >= 当前头的骑士，同时防止越界
        while(left2 < m && arr2[left2] < arr1[left1]){
            left2++;
        }
        // 如果骑士用完了还没找到合适的
        if(left2 >= m){
            cout << "you died!" << endl;
            return 0;
        }
        cost += arr2[left2];
        left1++;
        left2++;
    }
    cout << cost << endl;
    return 0;
}
```
