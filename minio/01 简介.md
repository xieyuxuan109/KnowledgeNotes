## minio是什么
```
MinIO 是一个高性能、开源的对象存储服务，基于 Apache License v2.0 协议。它兼容 Amazon S3 API，专为存储大容量非结构化数据（如图片、视频、日志文件等）而设计，支持单个对象最大可达 5TB。MinIO 以其轻量级和高性能特点，广泛应用于云原生存储、大数据处理和 AI/ML 数据湖等场景。
```
## 在官网获取license 有时间限制 尽快启动容器使用
```
mkdir -p $HOME/minio/data $HOME/minio/certs
Download the license file to $HOME/minio/minio.license for use in later steps.
```
## 部署minio
```
docker pull quay.io/minio/aistor/minio
docker run -dt                                             \
  -p 9000:9000 -p 9001:9001                                \
  -v /home/jasper/minio/data:/mnt/data                            \
  -v /home/jasper/minio/minio.license:/minio.license              \
  -v /home/jasper/minio/certs:/etc/minio/certs                    \
  --name "aistor-server"                                   \
  quay.io/minio/aistor/minio:latest minio server /mnt/data \
  --license /minio.license

docker logs aistor-server
```
