## App.vue里面三种标签
```
<template>
html
</template>

<script (lang="ts"可以消除里面写js的小警告)>
//js或ts
</script>

<style>
//样式
</style>
```
```
<!-- template标签定义组件的HTML模板部分 -->
<template>
<!-- 根div，应用CSS类"app" -->
<div class="app">
    <!-- h1标题显示"你好啊！" -->
    <h1>你好啊！</h1>
</div>
</template>

<script>
// script标签定义组件的JavaScript逻辑
    export default{
        // 组件名称为'APP'，用于调试和递归
        name:'APP'
    }
</script>

<style>
/* style标签定义组件的CSS样式，作用于当前组件（如果scoped）但这里未加scoped，为全局样式 */
    .app{
        /* 背景颜色为浅灰色 */
        background-color: #ddd;
        /* 添加阴影，模糊半径10px，无偏移，颜色默认黑色 */
        box-shadow: 0 0 10px;
        /* 圆角边框10px */
        border-radius: 10px;
        /* 内边距20px */
        padding: 20px;
    }
</style>
```
