## 扩容 安装 growpart（如果没有）
```
apt update
apt install -y cloud-guest-utils
```
## 扩展 sda3 分区
```
growpart /dev/sda 3
```
## 扩展 LVM Physical Volume
```
扩展 LVM Physical Volume
```
## 扩展 Logical Volume
```
lvextend -l +100%FREE -r /dev/ubuntu-vg/ubuntu-lv
```
