## 先部署基础设施
```
mysql - redis - es - blogx_server - blogx_web
```
## mysql
```
1.先解决环境变量 
  密码等需要加密的用Secret MYSQL_ROOT_PASSWORD  
  普通的环境变量ConfigMap MYSQL_DATABASE
  直接设置到yaml文件中 TZ
2.在配置PV/PVC PVC可以直接挂载到statefulset
  ConfigMap 文件 - ./master/my.cnf:/etc/mysql/my.cnf - ./master/blogx.sql:/docker-entrypoint-initdb.d/blogx.sql
  PV/PVC       - ./master/mysql-files:/var/lib/mysql-files - ./master/data:/var/lib/mysql - ./master/log:/var/log/
3.写satefulset svc yaml文件 3306seret
```

```
# StatefulSet
apiVersion: apps/v1
kind: StatefulSet
metadata:
  name: mysql-master
spec:
  serviceName: mysql-headless  # 关联 Headless Service
  replicas: 1
  selector:
    matchLabels:
      app: mysql-master
  template:
    metadata:
      labels:
        app: mysql-master
    spec:
      containers:
      - name: mysql
        image: mysql:8.0
        env:
        - name: MYSQL_ROOT_PASSWORD
          valueFrom:
            secretKeyRef:
              name: mysql-root-password
              key: MYSQL_ROOT_PASSWORD
        - name: MYSQL_DATABASE
          valueFrom:
            configMapKeyRef:
              name: mysql-config
              key: MYSQL_DATABASE
        - name: TZ
          value: "Asia/Shanghai"
        command:
        - "--default-authentication-plugin=mysql_native_password"
        - "--character-set-server=utf8mb4"
        - "--collation-server=utf8mb4_general_ci"
        - "--explicit_defaults_for_timestamp=true"
        - "--lower_case_table_names=1"
        - "--max_allowed_packet=128M"
        ports:
        - containerPort: 3306
        volumeMounts:
        - name: mysql-data
          mountPath: /var/lib/mysql
  # 自动为每个 Pod 创建独立的 PVC
  volumeClaimTemplates:
  - metadata:
      name: mysql-data
    spec:
      accessModes: ["ReadWriteOnce"]
      resources:
        requests:
          storage: 10Gi
      # 如果需要指定 StorageClass，可添加 storageClassName: "your-storageclass"
```
