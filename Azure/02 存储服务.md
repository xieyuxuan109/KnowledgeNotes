## 如何上传数据
```
第一种：在网站上传 找到创建的storage account => storage browser => container => upload
第二种：下载storage explorer => 在网站上获取 access key => 通过access key连接相应account => 上传account
```
## storage account访问方式
```
shared key 通过access key在代码中可以访问storage account 权限最大
SAS 共享访问签名 限制服务、操作的权限 时间的限制
Azure AD的身份验证 基于角色进行分配
匿名访问 => 在storageaccount页面更改权限设置，更改为匿名可访问
```
